# Bernard the Forge

A free idle / incremental game about an angry blacksmith, a goblin workforce with union issues, and a final boss with helmet issues.

- **Play here, or install it on your phone:** https://batemane.github.io/bernard-the-forge/
- Game page, downloads and devlogs: https://geewer-studio.itch.io/bernard-la-forge-20
- Discord: https://discord.gg/gGP7aXMjSZ

## Add it to your home screen

**iPhone / iPad (Safari):** open the link above, tap the Share button, then "Add to Home Screen".

**Android (Chrome):** open the link above, tap the menu (three dots), then "Install app" or "Add to Home screen".

The game then opens full screen, like an app. To bring a save from another device, use TO CLOUD / FROM CLOUD in the game: it gives you a 12-character code.

This repository only holds the exported web build. Made by geewer studio.
